# Berlin Urban Heat Twin

A research-oriented urban heat digital twin for Berlin that combines official urban-climate information with genuine meteorological observations while preserving scientific provenance and uncertainty.

The project is **not** a street- or building-level physical simulation. It explicitly distinguishes measured observations, officially modelled urban-climate data, transparent derived indicators and hypothetical scenarios.

Development follows test-driven, reproducible research-software principles. Full architecture, ingestion, API, visualisation and methodology are added progressively in subsequent commits.
